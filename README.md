# Mary's Notes

A simple personal notes and task app with two sections: **Notes** and **Tasks**.

## Features

### Notes
- Create, edit and delete notes.
- See the date associated with each note.

### Tasks
- Add tasks and assign dates and times.
- Keep tasks and notes organised in one place.

## Run locally

    npm install
    npm run dev

## Build

    npm run build

The app is built with React, TypeScript and Vite.
